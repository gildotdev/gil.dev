This site is a digital garden built to make publishing small, useful pieces of work feel easy. It favors readable pages, durable links, and ideas that can keep changing instead of waiting to become finished articles.

## Platform

- Powered by [Astro 7](https://astro.build/) with Markdown and MDX content collections.
- Styled with [Tailwind CSS 4](https://tailwindcss.com/) and a small set of site-specific styles.
- Organized as a [pnpm](https://pnpm.io/) monorepo containing the website and Gil Publisher, the custom Obsidian plugin that publishes notes and their related files.
- Built and hosted on [Netlify](https://netlify.com/).

## Type and color

[Departure Mono](https://departuremono.com/) gives headings and display text their pixel character. [Dank Mono](https://philpl.gumroad.com/l/dank-mono) is used for body copy and code.

The color system comes from the [Rosé Pine palette](https://rosepinetheme.com/palette/): Rosé Pine Dawn is the default light theme, while Rosé Pine provides the dark theme. The display controls in the footer remember the selected theme on this device.

## Motion and accessibility

The motion control can quiet the avatar, cards, text wiggles, and interface transitions. The site follows the device’s reduced-motion preference until a choice is saved, then remembers that choice alongside the theme.

Sometimes the whole system is fueled by [burritos 🌯](/chipotle).
